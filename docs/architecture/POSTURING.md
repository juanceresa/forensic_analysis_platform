## Strategic Relationship Model

### Phase 1: Pilot (Current)

**Timeline:** Now → 12 months

**Farmer House Role:**
- Full involvement in methodology development
- Robert as director, Juan as research assistant
- Ceresa case as founding demonstration
- Document everything for publication

**Civic Table Role:**
- Build platform

- Learn and iterate

**Output:**
- Validated methodology
- Working platform
- Founding case study
- Draft publication

### Phase 2: Publication (6-12 months)

**Timeline:** Before Robert leaves Farmer House

**Critical Action:** Robert publishes methodology

**Publication Options (in order of preference):**

1. **Academic Journal Article** (Best)
   - Submit to *Transitional Justice Review*, *Archival Science*, or *Journal of Human Rights*
   - Peer-reviewed, permanent scholarly record
   - Title: "Documentary Recovery as Civic Infrastructure: A Methodology for Post-Revolutionary Property Claims"
   - Affiliation: James L. Farmer House at Huston-Tillotson University

2. **White Paper** (Good)
   - Publish on Farmer House website + SSRN
   - Citable, permanent DOI
   - Less prestigious than journal but faster

3. **Method Guide** (Minimum)
   - Detailed technical documentation
   - Published open-access
   - Enough detail for replication

**Why This Matters:**
- Creates permanent, citable reference
- Doesn't depend on ongoing Farmer House involvement
- Anyone can read it, but Civic Table has the implementation
- Protects against Robert leaving or Farmer House relationship ending

**What Gets Published:**
- Full methodology (OCR → extraction → verification → graph)
- Validation results from pilot case
- Error budgets and acceptance criteria
- Ethical framework (UPL shield, forensic facts not legal strategy)
- **NOT published:** Proprietary code, client data, specific prompts

### Phase 3: Commercial Operation (Ongoing)

**Timeline:** After publication

**Farmer House Role (Optional):**
- Offer "Farmer House Verified" as premium service tier
- Provide ongoing methodology refinement (if desired)
- Academic validation for complex cases

**Civic Table Role:**
- Primary service provider
- Uses "the published Farmer House methodology"
- Owns client relationships and revenue

**Marketing Language:**
- "Using methodology developed at the James L. Farmer House at Huston-Tillotson University"
- "Based on research by Dr. Robert Ceresa" (permanent attribution)
- "Optional institutional verification available"

**If Robert Leaves Farmer House:**
- Core business unaffected (methodology is published)
- Drop "Farmer House Verified" premium tier
- Continue using published methodology
- Robert can still consult as individual scholar

## Verification Tier Model (Updated)

### The New Structure

| Tier | Label | Provider | Dependency | Cost to Client |
|------|-------|----------|------------|----------------|
| `TIER_3_AI` | AI Extracted | Civic Table platform | None | Base |
| `TIER_2_ANALYST` | Analyst Verified | Civic Table analyst | None | Medium |
| `TIER_2_INSTITUTIONAL` | Farmer House Verified | Farmer House analyst | Robert at FH | Premium |
| `TIER_1_CERTIFIED` | Legally Certified | External legal body (FCSC, notary) | None | Highest |

### Tier Details

**TIER_3_AI — AI Extracted**
- Automated extraction from OCR + Claude API
- Confidence score provided
- **Must display disclaimer:** "This data is AI-extracted and unverified"
- Color: Grey (#6B7280)
- Who: Civic Table platform (automated)
- Cost: Included in base service

**TIER_2_ANALYST — Analyst Verified**
- Human analyst at Civic Table reviews and confirms
- Analyst checks against source documents
- Adds verification notes
- Color: Gold (#F59E0B)
- Who: Civic Table employed analysts
- Cost: Standard verification fee
- **This is Civic Table's core offering**

**TIER_2_INSTITUTIONAL — Farmer House Verified (Optional)**
- Analyst at Farmer House independently verifies
- Uses published methodology standards
- Institutional stamp of approval
- Color: Gold with "FH" badge (#F59E0B + badge)
- Who: Farmer House analyst (while Robert is director)
- Cost: Premium verification fee
- **This is an add-on, not a requirement**

**TIER_1_CERTIFIED — Legally Certified**
- External legal authority certification
- Examples: FCSC claim approval, notarization, court acceptance
- Admissible in legal proceedings
- Color: Blue (#3B82F6)
- Who: External legal bodies
- Cost: Legal process fees (passed through)

### Key Differences from Old Model

**Old Model:**
```
TIER_3_AI → TIER_2_VERIFIED → TIER_1_CERTIFIED
```
Problem: "TIER_2_VERIFIED" implied only one verification path

**New Model:**
```
TIER_3_AI → TIER_2_ANALYST (Civic Table)
          ↘ TIER_2_INSTITUTIONAL (Farmer House, optional)
                                → TIER_1_CERTIFIED
```
Benefit: Civic Table can operate independently, Farmer House is premium add-on

### What This Means for Clients

**Base Service (No Farmer House Required):**
- TIER_3_AI extraction (automated)
- TIER_2_ANALYST verification (Civic Table analyst)
- Complete dossier
- Sufficient for most family use cases

**Premium Service (Farmer House Available):**
- All above +
- TIER_2_INSTITUTIONAL verification (Farmer House analyst)
- Institutional stamp for legal proceedings
- Higher credibility with attorneys/courts

**If Farmer House Relationship Ends:**
- Base service continues unchanged
- Premium tier removed from offering
- Existing TIER_2_INSTITUTIONAL verifications remain valid (historical)
- Future work uses TIER_2_ANALYST only

## The Crown Jewel: Implementation, Not Methodology

### What Others Can Copy (If Published)

- The methodology (that's the point of publishing)
- The general approach
- The error budgets
- The verification framework

### What They Can't Copy

1. **The Platform** — Civic Table owns the code
2. **Client Relationships** — Civic Table owns the pipeline
3. **The Founding Case** — Ceresa archive is proprietary training data
4. **First-Mover Advantage** — You're already operating when they're reading the paper
5. **Institutional Relationships** — Cuban-American legal community knows you
6. **The Implementation** — Knowing the recipe ≠ running the restaurant

**Analogy:**
- Published methodology = Recipe for croissants
- Civic Table platform = The bakery with trained bakers, equipment, supplier relationships, and happy customers

Anyone can read the croissant recipe. Most won't try to bake. Those who try won't do it well. Those who do it well won't scale it.

**What we say:**
- "This document states Mario Ceresa owned the mill in 1958" ✅
- "OCR confidence is 72%" ✅
- "Three documents corroborate this ownership claim" ✅

- "This proves ownership" ❌
- "You will win $2M in restitution" ❌
- "This is admissible in court" ❌

**Both entities position as:**
- Forensic fact-finders
- Independent standard
- Pre-litigation intelligence providers

## Risk Mitigation

### What If Robert Leaves Farmer House?

**Scenario:** Robert gets job elsewhere, Farmer House relationship ends

**Impact:**
- Lose access to "Farmer House Verified" premium tier
- Methodology remains (it's published)
- Robert can consult as individual scholar

**Mitigation:**
1. **Publish methodology NOW** — Before he leaves, while he has FH affiliation
2. **Don't build dependency** — Make Farmer House verification optional, not required
3. **Robert as advisor** — He can join Civic Table advisory board
4. **Other institutions** — Partner with new university if needed (methodology is portable)

### What If Competitor Uses Published Methodology?

**Scenario:** Someone reads the paper and starts competing service

**Why we're protected:**
1. **First-mover advantage** — We're already established
2. **Founding case** — We have proprietary training data (Ceresa archive)
3. **Platform** — They'd have to build from scratch
4. **Relationships** — Cuban-American community knows us
5. **Implementation** — Recipe ≠ Restaurant

**Response:**
- Welcome it (validates the methodology)
- Emphasize our track record
- Highlight Civic Table's superior platform
- Offer training/partnership instead of competition

### What If Farmer House Wants to Control Methodology?

**Scenario:** FH tries to assert ownership, restrict Civic Table's use

**Why we're protected:**
1. **Robert is author** — He controls publication
2. **Published = public** — Can't restrict use of published work
3. **No exclusive agreement** — (Don't sign one)

**Mitigation:**
- **Don't sign exclusivity** — Keep right to use published methodology
- **Clear IP agreement** — Civic Table owns platform code
- **Publication first** — Get methodology into public domain ASAP
