## Overview

The intake module sits at the start of the processing pipeline. It converts PDF documents into individual page images with metadata tracking, ready for the preprocessing stage.

### Core Responsibilities

1. **PDF Loading** - Extract pages from PDFs to PNG images (300 DPI)
2. **Provenance Tracking** - Create immutable metadata for chain of custody
3. **Manifest Management** - Track batch processing status and errors
4. **Multi-Part Document Handling** - Combine related PDFs into logical documents

## Multi-Part Document Handling

### Problem

Many scanned documents are split across multiple PDF files:

```
8 27 1958 Last Will Testament.pdf
8 27 1958 Last Will Testament.1pdf.pdf
8 27 1958 Last Will Testament.2pdf.pdf
8 27 1958 Last Will Testament.3pdf.pdf
```

### Solution

**DocumentGrouper** detects filename patterns and groups related files:

1. Strip common suffixes: `.1pdf.pdf`, `.2pdf.pdf`, `_part1.pdf`, etc.
2. Group files by base filename
3. Sort parts numerically
4. Extract pages sequentially across all parts

**Example:**

```
Input:
- "Last Will Testament.pdf" (3 pages)
- "Last Will Testament.1pdf.pdf" (2 pages)
- "Last Will Testament.2pdf.pdf" (4 pages)

Output:
- DOC-001/page_001.png through page_009.png (sequential numbering)
```

### Grouping Patterns

Recognized suffixes (case-insensitive):
- `.1pdf.pdf`, `.2pdf.pdf`, `.3pdf.pdf`, ...
- `_part1.pdf`, `_part2.pdf`, ...
- ` (1).pdf`, ` (2).pdf`, ...
- `-1.pdf`, `-2.pdf`, ...

### 1. DocumentGrouper

```python
class DocumentGrouper:
    """Group multi-part PDF files into logical documents."""

    def group_documents(self, pdf_files: List[Path]) -> Dict[str, List[Path]]:
        """
        Group PDFs by base filename.

        Args:
            pdf_files: List of PDF file paths

        Returns:
            Dict mapping logical document name to list of PDF parts (sorted)

        Example:
            {
                "Last Will Testament": [
                    Path("Last Will Testament.pdf"),
                    Path("Last Will Testament.1pdf.pdf"),
                    Path("Last Will Testament.2pdf.pdf")
                ]
            }
        """

    def _extract_base_name(self, filename: str) -> str:
        """Remove multi-part suffixes to get base name."""

    def _extract_part_number(self, filename: str) -> int:
        """Extract part number from filename (0 if no part number)."""
```

### 2. PDFLoader

```python
class PDFLoader:
    """Extract page images from PDF documents."""

    def __init__(self, dpi: int = 300):
        """Initialize with target DPI for extraction."""
        self.dpi = dpi

    def load_document_group(
        self,
        pdf_parts: List[Path],
        output_dir: Path
    ) -> List[Path]:
        """
        Extract pages from multiple PDF parts into sequential images.

        Args:
            pdf_parts: List of PDF files (sorted) that form one document
            output_dir: Directory for output images (e.g., raw_images/DOC-001/)

        Returns:
            List of all page image paths in order

        Raises:
            PDFLoadError: If any PDF cannot be read or is corrupted
        """

    def _extract_page(self, page: fitz.Page, output_path: Path) -> None:
        """Extract single page to PNG at target DPI."""
```

### 3. ProvenanceTracker

```python
class ProvenanceTracker:
    """Track document provenance and chain of custody."""

    def create_provenance(
        self,
        document_id: str,
        pdf_parts: List[Path],
        page_count: int,
        status: str,
        missing_parts: List[int] = None
    ) -> Dict[str, Any]:
        """
        Create provenance metadata for a document.

        Args:
            document_id: Unique document identifier (e.g., "DOC-001")
            pdf_parts: List of source PDF files
            page_count: Total pages extracted
            status: "success" or "failed"
            missing_parts: List of missing part numbers (optional)

        Returns:
            Provenance dict with hashes, timestamps, metadata
        """

    def save_provenance(self, provenance: Dict[str, Any], output_path: Path):
        """Write provenance JSON to disk."""

    def _compute_file_hash(self, file_path: Path) -> str:
        """Compute SHA-256 hash of file."""
```

### 4. ManifestManager

```python
class ManifestManager:
    """Manage case intake manifest."""

    def __init__(self, case_id: str):
        """Initialize manifest for a case."""
        self.case_id = case_id
        self.documents = []
        self.intake_timestamp = datetime.now()

    def add_document(
        self,
        document_id: str,
        filename: str,
        status: str,
        part_count: int,
        page_count: int,
        error: Optional[str] = None
    ):
        """Add document to manifest."""

    def save_manifest(self, output_path: Path):
        """Write manifest JSON to disk."""

    def get_summary(self) -> Dict[str, int]:
        """Return success/failure/skipped counts."""
```

## Error Handling

### Error Scenarios

| Scenario | Detection | Action | Manifest Status |
|----------|-----------|--------|-----------------|
| Corrupted PDF | PyMuPDF raises exception | Log error, skip document | `"failed"` |
| Empty PDF | Page count = 0 | Log error, skip document | `"failed"` |
| Missing parts | Gap in part sequence | Warn, process available parts | `"success"` with `missing_parts` field |
| Duplicate filename | Same base name, different hash | Add suffix to document_id | `"success"` |
| Non-PDF file | Extension check | Skip with warning | `"skipped"` |
| Extraction failure | Image write fails | Log error, mark document failed | `"failed"` |

### Validation Rules

**Before Processing:**
- File exists and is readable
- File extension is `.pdf` (case insensitive)
- File size > 0 bytes
- PDF can be opened by PyMuPDF

**During Processing:**
- Extract at least 1 page successfully
- Generated images are valid PNG files
- Image dimensions > 0

**After Processing:**
- Page count matches extracted image count
- All provenance files written successfully
- Manifest updated

## CLI Integration

### Command

```bash
python cli.py intake CASE-001
```

### Implementation

```python
@click.command()
@click.argument("case_id")
def intake(case_id: str):
    """Process PDF intake for a case."""

    input_dir = Path(f"input/{case_id}/documents")
    output_dir = Path(f"output/{case_id}")

    # Initialize components
    grouper = DocumentGrouper()
    loader = PDFLoader(dpi=300)
    provenance_tracker = ProvenanceTracker()
    manifest = ManifestManager(case_id)

    # Find and group PDFs
    pdf_files = list(input_dir.glob("*.pdf"))
    document_groups = grouper.group_documents(pdf_files)

    # Process each document group
    for doc_id, (base_name, pdf_parts) in enumerate(document_groups.items(), start=1):
        document_id = f"DOC-{doc_id:03d}"

        try:
            # Extract pages
            page_paths = loader.load_document_group(
                pdf_parts,
                output_dir / "raw_images" / document_id
            )

            # Create provenance
            provenance = provenance_tracker.create_provenance(
                document_id, pdf_parts, len(page_paths), "success"
            )
            provenance_tracker.save_provenance(
                provenance,
                output_dir / "intake" / "provenance" / f"{document_id}_provenance.json"
            )

            # Update manifest
            manifest.add_document(
                document_id, base_name, "success",
                len(pdf_parts), len(page_paths)
            )

        except Exception as e:
            logger.error(f"Failed to process {base_name}: {e}")
            manifest.add_document(
                document_id, base_name, "failed", 0, 0, error=str(e)
            )

    # Save manifest
    manifest.save_manifest(output_dir / "intake" / "manifest.json")

    # Print summary
    summary = manifest.get_summary()
    click.echo(f"Intake complete: {summary['successful']} success, {summary['failed']} failed")
```
