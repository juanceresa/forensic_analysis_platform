## Overview

Add a dossier download option to the Dashboard's workflow checklist. When an admin has generated a dossier PDF via CLI, clients see a download button as the final workflow step.

**Approach:** Pre-generated availability (not on-demand generation)
- Admin generates dossier offline using `python cli.py generate-dossier CASE-ID`
- Frontend checks if PDF exists, shows download button if available
- Aligns with "no self-service" architecture and consulting model

## API Route

**Endpoint:** `/api/cases/[caseId]/dossier`

**Methods:**
- `HEAD` — Check if dossier exists (200 or 404)
- `GET` — Download the PDF file

**File:** `farmer_vault/app/api/cases/[caseId]/dossier/route.ts`

```typescript
import { existsSync, readFileSync } from 'fs';
import path from 'path';
import { NextRequest } from 'next/server';

// TODO: Add auth check - Phase 8B
// TODO: Add audit logging - Phase 8B

export async function GET(
  request: NextRequest,
  { params }: { params: { caseId: string } }
) {
  const { caseId } = params;
  const pdfPath = path.join(
    process.cwd(),
    '..',
    'cases',
    caseId,
    'output',
    `${caseId}_dossier.pdf`
  );

  if (!existsSync(pdfPath)) {
    return new Response('Dossier not found', { status: 404 });
  }

  const file = readFileSync(pdfPath);
  return new Response(file, {
    headers: {
      'Content-Type': 'application/pdf',
      'Content-Disposition': `attachment; filename="${caseId}_dossier.pdf"`,
    },
  });
}

export async function HEAD(
  request: NextRequest,
  { params }: { params: { caseId: string } }
) {
  const { caseId } = params;
  const pdfPath = path.join(
    process.cwd(),
    '..',
    'cases',
    caseId,
    'output',
    `${caseId}_dossier.pdf`
  );

  return new Response(null, {
    status: existsSync(pdfPath) ? 200 : 404
  });
}
```

## UI Changes

### Location
Dashboard page → WorkflowChecklist component → New final step

### Workflow Steps (updated)
1. ✓ Documents processed (X/Y)
2. ✓ Entities extracted (N)
3. ○ Verification pending (M items)
4. ○ Dossier ready → [Download PDF]  ← **NEW**

### Display States

**When dossier is available:**
```
✓ Dossier ready                    [Download PDF]
```

**When dossier is not yet generated:**
```
○ Dossier in preparation
```

### Component Logic

```typescript
// In WorkflowChecklist or Dashboard
const [dossierAvailable, setDossierAvailable] = useState(false);
const [checkingDossier, setCheckingDossier] = useState(true);

useEffect(() => {
  fetch(`/api/cases/${caseId}/dossier`, { method: 'HEAD' })
    .then(res => {
      setDossierAvailable(res.ok);
      setCheckingDossier(false);
    })
    .catch(() => {
      setDossierAvailable(false);
      setCheckingDossier(false);
    });
}, [caseId]);

const handleDownload = () => {
  window.open(`/api/cases/${caseId}/dossier`, '_blank');
};
```
